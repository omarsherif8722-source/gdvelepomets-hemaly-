# Official Brochures Folder

Drop official developer PDF files into this folder using the filenames below (or add custom filenames via **Broker Studio → + Add Brochure**).

How automatic detection works:
- When a visitor clicks **Download / Print PDF**, `js/brochures.js` checks whether the PDF exists at `fileUrl`.
- **If the PDF file exists here**, the browser downloads/opens the official developer PDF immediately.
- **If the PDF has not been uploaded yet**, the site automatically opens a branded, print-ready Architectural Dossier PDF so there are **never any broken links or 404 errors**.
